# Context1008 — Khởi tạo gọn migration Backend V1

- `v1-migrate` dùng bản SQL 0031 cho schema `public` chưa có bảng V1 và chỉ khi
  revision đích trùng bản gộp. Tạo schema và ghi revision cùng giao dịch có khóa.
  DB có revision hoặc head mới chạy chuỗi Alembic thường.
- `v1-db-check` là giao dịch chỉ đọc. DB đang cấu hình báo
  `0031_spelling_defaults (head)`. Kiểm tra phụ thuộc `dev` đạt.
- 63 bảng ứng dụng, schema khớp với chuỗi lịch sử trên DB cô lập sau chuẩn hóa
  cách in cùng phép ép kiểu. Migration 6 ca và launcher 25 ca đạt. Full suite
  backend đang chạy cô lập tại thời điểm ghi.
