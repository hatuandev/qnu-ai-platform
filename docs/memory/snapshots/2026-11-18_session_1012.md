# Context1012 — Xóa kho tri thức kèm lịch sử hội thoại

- Người dùng gỡ kho khỏi trợ lý nhưng không xóa được vì còn hội thoại/bài kiểm
  thử cũ ghim `collection_id` (tham chiếu ngữ nghĩa, không FK). Chọn phương án
  "Thêm bước xóa kèm lịch sử".
- Backend: `graph_for_collection(include_history=...)`; `COLLECTION_TABLES` thêm
  `chat_conversations`, `kb_answer_reviews`, `kb_answer_review_items`;
  `_add_collection_history()` gom hội thoại + lượt hỏi + bài kiểm thử + mục;
  `collection_history_counts()` phục vụ chặn và impact. `PreviewRequest` thêm
  `include_history` (chỉ cho collection/delete); purge đọc lại cờ khi kiểm tra,
  xác nhận và thực thi; impact có `history_included`,
  `conversations_to_delete`, `answer_reviews_to_delete`,
  `history_available_to_delete`.
- Frontend: hộp thoại xóa kho nhận 409 `collection_in_use_by_*` → bảng cảnh báo
  cam + ô "Xóa cả lịch sử hội thoại cũ"; preview lại kèm lịch sử; hiện số hội
  thoại/bài kiểm thử sẽ xóa; nút xóa chỉ bật khi preview hợp lệ.
- Lỗi thật gặp: worker `source_purge_incomplete error_type=KeyError` vì ARQ
  không nạp model `answer_review` (`Base.metadata.tables` thiếu
  `kb_answer_reviews`). Sửa bằng đăng ký model `answer_review` +
  `conversations` trong `qnu/workers/settings.py`, cùng chỗ với
  `knowledge.review` đã có.
- Kiểm chứng: Ruff + format đạt các tệp backend; Biome và tsc đạt FE; import
  smoke xác nhận bảng đã đăng ký.
- Sống: preview kèm lịch sử + accept qua API :8002; worker lần 3 trả
  `completed` (0,75 giây). DB đọc lại: mọi bảng của `col_af3ea7d6d5fb` = 0
  (gồm 35 hội thoại, 3 bài kiểm thử, 12 dòng upload, 2 index run); kho còn lại
  `col_e07f7b7ebb1b` nguyên vẹn (1 nguồn); trợ lý `ast_44fc63a77512` còn,
  `collection_id = NULL`; workspace còn 0 hội thoại.
