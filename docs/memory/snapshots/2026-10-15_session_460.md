# Snapshot phiên 460 — Dev login production

Theo yêu cầu người dùng, bổ sung DEV_AUTH_ALLOW_IN_PRODUCTION để dùng cùng DEV_AUTH_ENABLED trên demo HTTPS, mặc định false. Mật khẩu riêng >=24 ký tự, SECRET_KEY >=32/HS256, ALLOWED_ORIGINS origin HTTPS chính xác. SSO có thể tắt khi gate hợp lệ. Production không cấp anonymous actor; token riêng, hết hạn tối đa 60 phút, đổi mật khẩu vô hiệu hóa phiên cũ sau recreate API. Redis throttle chia sẻ/fail-closed và Origin validation.

Regression trước 3 fail/9 pass; focus sau 87 pass; Redis cô lập + HTTP login/protected API đạt 1 pass. Khi yêu cầu dừng, full suite đã tự hoàn tất: 1370 pass/11 fail trùng tên baseline/16 skip, 213,45 giây. Không chạy thêm kiểm tra theo yêu cầu. Import-order cuối đã chỉnh chưa rerun. Chưa commit/push/deploy/server verify, không DB reset, không FE/RAG/backup.
