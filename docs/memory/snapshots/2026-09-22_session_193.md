## Tóm Tắt Vấn Đề & Nguyên Nhân Gốc Rễ
Người dùng chạy:
- `uv run python -m app.cli db seed --document-types`
- `uv run python -m app.cli db seed --all`
- `uv run python scripts/seed_document_types.py`
và bị lỗi `UndefinedTableError: relation "platform_document_types" does not exist`.

Nguyên nhân:
1. Database PostgreSQL chưa được áp dụng các file Alembic migration lên HEAD nên bảng `platform_document_types` chưa được tạo.
2. Khi chạy migrate tự động, Alembic bị chặn bởi 3 lỗi liên hoàn:
   - **Orphan facts**: Migration `20260919_facts_foreign_key_and_schema_sync.py` tạo Foreign Key `CASCADE` trỏ tới `knowledge_documents` trong khi DB có 772 orphan records.
   - **Alembic version_num VARCHAR(32) truncation**: Revision ID dài 43 ký tự khiến Postgres ném lỗi `StringDataRightTruncationError`.
   - **Thiếu DDL `conversation_threads`**: Migration `20260922_conversation_feedback.py` tạo FK trỏ sang `conversation_threads.id` nhưng bảng này chưa từng có migration tạo bảng.
   - **Thiếu async connection commit**: `alembic/env.py` thiếu `await connection.commit()` khi chạy `run_async_migrations`.
