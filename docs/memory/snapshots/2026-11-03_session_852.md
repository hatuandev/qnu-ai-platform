# Snapshot 852 — Rà soát nền và dừng lượt

- Studio tạo review nền bằng `POST /reviews?background=true` với khóa idempotency, đọc tiến độ theo ID và dừng qua `POST /reviews/{review_id}/cancel`.
- ARQ nhận lượt `queued`. Trạng thái dừng giữ các nhóm đã hoàn tất và phản ánh kết quả upstream chưa xác định nếu request đã gửi.
- Migration `0013_queued_review` cần áp dụng trước khi chạy API và worker mới. Kiểm thử trọng tâm dùng DB cô lập và model giả.
