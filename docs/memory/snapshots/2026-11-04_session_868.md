# Context868 — Cửa sổ ngữ cảnh của trợ lý mới

Mặc định tạo trợ lý V1 là `context_window=1` ở form và API. Chọn `0` để tắt lấy
đoạn liền kề. Hội thoại ghim chính sách đã lưu. Snapshot cũ thiếu policy và API
hỏi đáp trực tiếp dùng mặc định tương thích `0`.
