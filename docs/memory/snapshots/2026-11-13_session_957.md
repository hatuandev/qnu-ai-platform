# Phiên 957 — Bỏ cấu hình model theo đơn vị (allowlist + model mặc định workspace)

- **Mục tiêu.** Người dùng duyệt "bỏ luôn cả hai": loại hoàn toàn allowlist provider và model mặc định theo workspace; `model_defaults` cấp hệ thống (dòng `id='system'`) là nguồn phân giải duy nhất; workspace chỉ còn là biên giới quyền.
- **Backend.** Gỡ endpoint `GET/PUT /workspaces/{id}/allowed-providers`, `PUT /workspaces/{id}/model-defaults`, DTO/schema, ORM `workspace_allowed_providers`/`workspace_model_defaults`, enforcement trong `catalog/service.py` và `resilience/routing.py` (primary = system default, fallback không theo grant), guard xóa connection chỉ còn kiểm `model_defaults`; bỏ 2 bảng khỏi `platform/ownership.py`; migration `0027_drop_ws_model_policy` (down_revision `0026_ollama_llamacpp`) và `0028_drop_index_system_default_authorized` (down_revision `0027`) + `SCHEMA_HEAD` = `0028_drop_index_system_default_authorized`.
- **Frontend.** FE V1 xóa `features/workspaces/allowlist-patch.ts`, `models-panel.tsx`, route `workspaces.$workspaceId.models.tsx`; sửa endpoints/permissions/settings hub/workspace/nav; 6 nhãn microcopy → "Theo mặc định hệ thống"; `tests/v1-contract.test.ts` cập nhật. FE V2 xóa endpoint/type/hook/request allowlist không còn dùng.
