# Snapshot phiên 524 — Hoàn thiện ba điểm còn sót DOCX → QNU RAG Markdown

- Lỗi 1 (`parsers/docling_structure.py`): `_span_pages()` + `map_unit_to_page()` xét
  **toàn bộ khoảng khớp** (`hit.start()` tới `hit.end()`) của mọi phép khớp, không chỉ
  điểm đầu; trả `(pages: list[int], cursor, state)` với state `spanning`. Đơn vị đa
  trang nhận **một `source_location` cho mỗi trang render** (`_locations()`), cùng
  locator `docx:block:N#rowM`; span có gap hoặc vượt vùng ghim → unknown (`page=null` +
  locator + cờ `page_unresolved`). Giữ forward-only, giữ "lặp ở nhiều trang là mơ hồ",
  giữ `aligned` chỉ khi không còn đơn vị chưa định vị; `unit_states` tách
  matched/spanning/ambiguous/absent/out_of_order. Trang vẫn là trang PDF render
  (`kind=pdf_preview_render`), không phải phân trang DOCX. Áp cho dòng bảng, ghi chú,
  anchor header và item list.
- Lỗi 2 (`normalization/qnu_markdown.py`): `_typed_in()` đặt `isinstance(str)` trước
  mọi tra cứu set — `review_status`, `type` khối, `state` field, `basis` origin, `type`
  khối con/origin. `context_refs` chỉ lặp khi là list (lỗi đã có do pass chính ghi).
  Quét placeholder dùng `str(metadata)` thay `json.dumps` để metadata hỏng kiểu không
  làm validator crash. `_construct_unique_mapping` kiểm `Hashable` trước `key in mapping`
  → khóa YAML phức tạp thành `block_metadata_yaml_error`. Không try/except rộng, không
  ép kiểu; field thuộc columns bảng cha, origin, ô gộp, số 0, mã 0 đầu, ô trống giữ nguyên.
- Lỗi 3 (`services/qnu_docx_artifacts.py`): `rebuild_qnu_markdown_for_revision` kiểm
  `structured_sha256` (thiếu → `unavailable/structured_checksum_missing`; sai định dạng
  `[0-9a-f]{64}` → `unavailable/structured_checksum_invalid`) **trước** khi đọc storage,
  rồi SHA-256 trên đúng bytes đọc được; lệch → `failed/structured_checksum_mismatch` +
  `expected_sha256`/`actual_sha256` + WARNING, không parse/render/ghi tệp mới, không lấy
  hash vừa tính làm giá trị kỳ vọng, không sửa artifact lịch sử.
- Regression (`tests/test_qnu_docx_markdown.py`): +`TestQnuUnitPageMapping` (7), +2 test
  builder cắt giữa dòng, +2 test validator sai kiểu (6 payload + khóa không băm),
  +3 test checksum; fixture `_ready` đổi từ `"d"*64` sang `compute_sha256(bytes)` thật +
