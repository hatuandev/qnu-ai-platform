# Snapshot672 — Tự đăng nhập local và xử lý nợ lint frontendV1

User yêu cầu hoàn thiện `frontendV1`: đọc trạng thái thật trước khi sửa, bỏ màn hình đăng nhập khi chạy local bằng cơ chế dev login sẵn có mà không lộ credential, sửa nợ lint còn lại, giữ nguyên các sửa Context671. RAG tiếp tục tạm dừng.

Baseline chạy lại đúng số liệu Context671: 134 test PASS, build/typecheck PASS, Biome FAIL 61 errors/12 warnings/6 infos trên 468 tệp. `frontendV1/` và `backendV1/` đều chưa được Git theo dõi nên đối chiếu bằng hash và artifact.

Đã thêm cầu nối tự đăng nhập chỉ tồn tại trong Vite dev server (`apply: "serve"`, đăng ký khi `command === "serve" && !isPreview && mode !== "production"`). Access key đọc từ `.env.local` trong tiến trình Node rồi gọi lại `POST /platform/v1alpha1/auth/login` sẵn có; trình duyệt chỉ nhận token và vẫn phải qua `/auth/me` trước khi mở trang bảo vệ. Chốt chặn: chỉ POST, `Host` loopback, `Origin` cùng origin (thiếu cũng từ chối), `sec-fetch-site: same-origin`, phải có access key, backend đích phải loopback. Client dùng lại `createV1Client` với `prefix: ""` nên mọi lời gọi mạng vẫn đi qua module được kiểm soát; có single-flight cho StrictMode. Đăng xuất đặt cờ boolean trong `sessionStorage` cộng latch bộ nhớ nên không tự đăng nhập lại; có nút mở lại tường minh. Backend không bị sửa.

Lint được sửa theo đúng nhóm lỗi Biome: helper hàng bảng dùng được bàn phím cho 8 màn hình, `label`/`htmlFor` và vùng kéo thả `label` + input `sr-only`, bỏ React key theo index, sửa hook deps bằng `useCallback`/ref, bỏ `any` ở `invoice-detail.tsx` và `excel-export.ts`, bỏ non-null assertion, sắp xếp import. Ba artifact QA JSON chuyển sang `storage/artifacts/qa-context650`; `biome.json` loại trừ đúng thư mục output, không loại trừ mã nguồn. Test ranh giới `template-boundary.test.ts` được **siết**: chỉ cho đúng một khoá boolean với giá trị literal `"1"`, phân giải hằng số, vẫn cấm `document.cookie`.

Kiểm chứng cuối: `npm test` 16 tệp **156 PASS / 0 FAIL / 0 SKIP** (giữ đủ 134 test cũ + 22 mới: 8 middleware, 8 UI, 6 bundle); `npm run lint` **PASS** 472 tệp 0/0/0; `npm run typecheck` PASS; `npm run build` PASS (còn cảnh báo chunk > 500 kB có từ trước); `npm ls --depth=0` PASS, không thêm dependency. Quét `dist/`: 0 lần `QNU_DEV_ACCESS_KEY=`, `createDevAutoLoginHandler`, `devAutoLoginPlugin`, `sec-fetch-site`.

Hai lỗi thật gặp khi làm: thông điệp `network_unreachable` bị gộp với `backend_unreachable` nên gợi ý sai — đã tách; và mã `network_unreachable` của transport không nằm trong `asErrorCode` nên rơi nhánh mặc định — đã xử lý tường minh. Không sửa assertion để che lỗi.
