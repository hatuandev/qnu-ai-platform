# Context1003 — Hướng dẫn agent về JSON, Markdown và ngân sách rà soát

- Giữ JSON cấu trúc và Markdown đọc/chỉnh sửa cùng phiên bản. Liên kết theo mã đoạn, khối và ô để giữ dẫn chứng và đối chiếu với JSON đã ghim.
- Ưu tiên kiểm nguyên văn đủ điều kiện ở backend. Gửi phần còn lại theo ngân sách ModelOps và giữ cơ chế chia an toàn khi cần. Chỉ lập chỉ mục các đoạn thuộc phiên bản đã phát hành.
- Số đo lịch sử trên cùng DOCX phức tạp ở phiên 1000 là 5 → 1 lượt Qwen, 102.050 → 10.094 token, 118,55 → 56,72 giây. Ghi rõ đây là kết quả trên một mẫu sau các tối ưu rà soát. Giới hạn ngữ cảnh mỗi request vẫn áp dụng.
