# QNU.AI Platform — Frontend Studio UI

Giao diện Quản trị và Điều phối Trợ lý AI Thông minh (Next.js 15, React 19, TypeScript), tích hợp Visual DAG Workflow Canvas, Quản lý Kho tri thức, Test Retrieval trực tiếp, Kênh phân phối & Live Human Handoff.

## 🛠️ Cài Đặt & Khởi Chạy

```powershell
# 1. Cài đặt thư viện
npm install

# 2. Chạy môi trường phát triển (Port 3000)
npm run dev
```

Truy cập: `http://localhost:3000`
