# assistants

Đã có [cấu hình trợ lý v1](../../../docs/assistants-conversations.md): một collection,
chat provider/default ModelOps, persona giọng văn, topK/history/output budget,
revision và active. Admin quản lý, không lưu credential tại assistant.

[RAG policy](../../../docs/rag-policies.md) lưu chiến lược tìm kiếm, scope metadata,
context window và kiểm chứng câu trả lời; hội thoại ghim policy trong snapshot.

Chưa có SSE, tool hoặc chia sẻ chatbot public. Xem `docs/feature-port-matrix.md`.
